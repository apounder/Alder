Download **Alder-<version>-Windows-x64-GUI-Setup.exe** from **Assets** below, open
it, and follow the installer. Python, Git, Conda, and Node.js are not required.

First launch opens **Set up Alder**. Uncheck every model for the viewer only,
or choose optional MLIP models and CPU/NVIDIA hardware. Setup downloads and
checks the selected calculation environments. UMA requires approved Hugging Face
access and a read token; MACE-OFF23 requires licence acknowledgement. Public
AIMNet2 and MACE-ANI-CC need no account.

Open **Alder** from Start or the optional desktop shortcut next time. Installed
models are reused. To add or repair models, open **Local MLIP → Environment /
models → Guided setup**.

The **Portable.zip** contains the same app: extract the complete folder and open
`Alder.exe`, keeping `_internal` beside it. The Windows build is unsigned.
`SHA256SUMS.txt` covers both downloads.

Mac and Linux users should follow the terminal installation instructions in the
[README](https://github.com/apounder/alder#installation).
