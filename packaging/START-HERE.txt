MOLECULE STUDIO FOR WINDOWS

Portable ZIP: right-click the ZIP, choose Extract All, open the extracted
MoleculeStudio or MoleculeStudio-MLIP-Offline folder, and double-click
MoleculeStudio.exe.
Keep the _internal folder next to the executable. For MLIP Offline, also keep
the complete mlip-offline folder. Do not run from inside the ZIP.

Installer: double-click MoleculeStudio-<version>-Windows-x64-<edition>-Setup.exe and
follow the installation and model-setup windows. Open Molecule Studio from the Start menu.
Installation is for your Windows account and does not require administrator
rights. Remove it through Windows Settings > Apps > Installed apps.

Python, npm, Node.js, a browser, and a localhost server are not required.
The editors, chemistry engine, and renderer are included and work offline.
Open files from inside Studio or drag files onto its window.

DOWNLOAD EDITIONS
GUI: viewer/editor and exports work offline. Local MLIP setup downloads its
calculation environment and public models when requested.
MLIP Offline: includes CPU environments for MACE, AIMNet2 and UMA, plus public
MACE-ANI-CC and four AIMNet2 models. In Guided setup, choose models and CPU to
install from bundled files. Setup configures paths and checks calculations for you.
Allow several GB of free disk space per calculator.

UMA and MACE-OFF23 weights are not included. Those still need model access or
licence acknowledgement and an online download. The bundles include neither
account credentials nor a CUDA runtime. Both editions have the same application
features.
Guided setup detects each computer's CPU and NVIDIA GPU. CUDA setup needs an
internet connection and a compatible NVIDIA driver. Reopen Local MLIP >
Environment / models > Guided setup to add models or repair CPU/GPU support.
UMA access and licence prompts appear before calculator downloads. A token alone
does not grant access to gated models; public models need no account.
Switching editions preserves separate calculation caches and job history.

Target: 64-bit Windows 10 (1809+) / Windows 11 with working graphics drivers.
Windows on ARM runs this x64 build through emulation; no native ARM64 build
is included. The initial build was checked on a Windows 11 ARM64 PC.
Current builds are unsigned; Windows may display an unknown-publisher warning.

If startup fails, diagnostics are written to:
%LOCALAPPDATA%\Molecule Studio\studio.log

Third-party notices are included in ThirdPartyLicenses and in
_internal\molecule_studio\assets\*-LICENSE*.txt.
